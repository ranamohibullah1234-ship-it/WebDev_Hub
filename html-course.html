HTML Tags, Definitions & Syntax

Understand each tag with a simple explanation and code example.

LESSON 01

HTML Document Structure

Definition: These elements create the basic structure of an HTML document. The head contains metadata, while the body contains the visible webpage content.

Syntax and Example

<!DOCTYPE html>
<html lang="en">
    <head>
        <title>My Website</title>
    </head>
    <body>
        <h1>Hello World!</h1>
    </body>
</html>
Tip: The DOCTYPE declaration tells the browser to use HTML5 standards.
LESSON 02

Heading Tags: <h1> to <h6>

Definition: Heading tags define titles and subtitles. HTML provides six heading levels, from h1 (highest level) to h6 (lowest level).

Syntax and Example

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subheading</h3>
<h4>Heading Four</h4>
<h5>Heading Five</h5>
<h6>Heading Six</h6>
LESSON 03

Paragraph Tag: <p>

Definition: The p tag is used to display a paragraph of text. Browsers normally add space before and after a paragraph.

Syntax and Example

<p>HTML is used to structure webpages.</p>
<p>CSS is used to style webpages.</p>
LESSON 04

Text Formatting Tags

Definition: These tags emphasize text, show importance, or provide different text formatting.

Syntax and Example

<b>Bold text</b>
<strong>Important text</strong>
<i>Italic text</i>
<em>Emphasized text</em>
<u>Underlined text</u>
<mark>Highlighted text</mark>
<small>Small text</small>
<del>Deleted text</del>
<ins>Inserted text</ins>
H<sub>2</sub>O
X<sup>2</sup>
LESSON 05

Anchor Tag: <a>

Definition: The anchor tag creates hyperlinks to other pages, websites, files or sections of the current page. The href attribute sets the destination.

Syntax and Example

<a href="about.html">About Us</a>

<a href="https://example.com"
   target="_blank"
   rel="noopener">
    Visit Website
</a>

<a href="#practice">Go to Practice</a>
LESSON 06

Image Tag: <img>

Definition: The img tag displays an image. The src attribute specifies the image location and alt provides alternative text describing the image.

Syntax and Example

<img
    src="images/photo.jpg"
    alt="A beautiful landscape"
    width="300"
>
Tip: The img element is a void element, so it does not require a closing tag.
LESSON 07

List Tags: <ul>, <ol>, <li>

Definition: ul creates an unordered (bulleted) list, ol creates an ordered (numbered) list, and li represents each list item.

Syntax and Example

<!-- Unordered list -->
<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

<!-- Ordered list -->
<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
</ol>

<!-- Description list -->
<dl>
    <dt>HTML</dt>
    <dd>Structures web content.</dd>
</dl>
LESSON 08

Line Break and Horizontal Rule

Definition: br starts a new line. hr represents a thematic break, often displayed as a horizontal line.

Syntax and Example

<p>Hello<br>Welcome to HTML.</p>

<hr>
LESSON 09

Division and Span Tags

Definition: div groups block-level content, while span groups a small part of text inline. Both are commonly used with CSS.

Syntax and Example

<div class="card">
    <h2>HTML Course</h2>
    <p>Learn <span class="highlight">HTML</span> today.</p>
</div>
LESSON 10

Semantic HTML Tags

Definition: Semantic elements describe the purpose of the content they contain, helping make webpage structure clearer and more accessible.

Syntax and Example

<header>Website Header</header>

<nav>
    <a href="mainpage.html">Home</a>
</nav>

<main>
    <section>
        <h2>About Us</h2>
        <p>Our main content.</p>
    </section>

    <article>An independent article</article>
    <aside>Related information</aside>
</main>

<footer>Copyright Information</footer>
LESSON 11

Table Tags

Definition: Tables display related information in rows and columns. tr creates a row, th creates a header cell and td creates a data cell.

Syntax and Example

<table>
    <thead>
        <tr>
            <th>Course</th>
            <th>Duration</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>HTML</td>
            <td>2 Weeks</td>
        </tr>
    </tbody>
</table>
LESSON 12

Form Tags

Definition: A form collects information from users. label describes an input, while textarea allows users to enter longer text.

Syntax and Example

<form action="/submit" method="post">
    <label for="username">Username:</label>
    <input
        type="text"
        id="username"
        name="username"
        required
    >

    <label for="message">Message:</label>
    <textarea id="message" name="message"></textarea>

    <button type="submit">Submit</button>
</form>
Note: A form needs a suitable server endpoint or other submission handling to process its data.
LESSON 13

Input Types

Definition: input creates interactive form controls. Its type attribute determines what kind of data a user can enter or select.

Syntax and Example

<input type="text" placeholder="Your name">
<input type="email" placeholder="Your email">
<input type="password" placeholder="Password">
<input type="number">
<input type="date">
<input type="checkbox">
<input type="radio" name="level">
<input type="file">
<input type="color">
<input type="range">
LESSON 14

Button Tag

Definition: The button element creates a clickable button. Its type can be button, submit or reset.

Syntax and Example

<button type="button">Click Me</button>

<button type="submit">Submit Form</button>

<button type="reset">Reset Form</button>
LESSON 15

Audio and Video Tags

Definition: audio embeds sound, while video embeds a video player. The controls attribute displays playback controls.

Syntax and Example

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

<video controls width="400">
    <source src="video.mp4" type="video/mp4">
    Your browser does not support video.
</video>
LESSON 16

HTML Attributes

Definition: Attributes provide additional information about elements. They are usually written inside the opening tag.

Syntax and Example

<p id="intro" class="highlight">
    Welcome to my website.
</p>

<img src="photo.jpg" alt="Sample photo">

<input type="text" placeholder="Enter your name">

Common attributes: id, class, href, src, alt, title, name, type, value and placeholder.

LESSON 17

HTML Comments

Definition: Comments are notes for developers. The browser does not display comment text as webpage content.

Syntax and Example

<!-- This is an HTML comment -->

<h1>Welcome to HTML</h1>
LESSON 18

HTML Entities

Definition: Character references let you display reserved characters or symbols that have special meaning in HTML.

Syntax and Example

&lt;       displays <
&gt;       displays >
&amp;      displays &
&nbsp;     adds a non-breaking space
&copy;     displays ©
&hearts;   displays ♥
LESSON 19

Iframe Tag

Definition: An iframe embeds another webpage or supported resource inside the current page. Some websites block iframe embedding.

Syntax and Example

<iframe
    src="https://example.com"
    title="Example website"
    width="400"
    height="250"
></iframe>
LESSON 20

Details and Summary Tags

Definition: details creates a disclosure widget. summary provides the visible heading that users click to expand or collapse it.

Syntax and Example

<details>
    <summary>What is HTML?</summary>
    <p>HTML structures webpage content.</p>
</details>
