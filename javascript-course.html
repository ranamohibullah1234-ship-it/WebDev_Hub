What is JavaScript?

JavaScript is a programming language used to make websites interactive.

First Program

console.log("Hello, World!");

Output:

Hello, World!
LESSON 02

Variables

Variables store information that we can use in a program. 

let age = 15;
const name = "Ali";
var city = "Lahore";

console.log(name);
console.log(age);
  • let: A variable whose value can be reassigned.
  • const: A variable that cannot be reassigned.
  • var: An older way to declare variables.
LESSON 03

Data Types

Data types describe the values used in JavaScript.

let name = "Ali";       // String
let age = 15;           // Number
let isStudent = true;   // Boolean
let result;             // Undefined
let value = null;       // Null
  • String: Text
  • Number: Numbers, including decimals
  • Boolean: true or false
  • Undefined: A variable without an assigned value
  • Null: An intentionally empty value
LESSON 04

Input & Output

console.log() displays information in the browser console. prompt() asks the user for input in a browser. 

let name = prompt("Enter your name");

console.log("Hello " + name);

Another example:

alert("Welcome to JavaScript!");

alert() displays a message box. The browser console is available through Developer Tools.

LESSON 05

Operators

Operators perform calculations and comparisons.

let a = 10;
let b = 3;

console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // Division
console.log(a % b);  // Remainder

console.log(a > b);  // true
console.log(a === b); // false

Main types: arithmetic, comparison and logical operators.

LESSON 06

If-Else Conditions

Conditions allow a program to make decisions. 

let age = 18;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Under 18");
}

Use else if when you need to check another condition.

LESSON 07

For & While Loops

Loops repeat a block of code multiple times.

For Loop

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

While Loop

let i = 1;

while (i <= 3) {
    console.log(i);
    i++;
}
LESSON 08

Arrays

An array stores multiple values in a single variable. 

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[0]);

fruits.push("Orange");

console.log(fruits.length);
  • Array indexing starts from 0.
  • push() adds an item to the end.
  • length gives the number of items.
LESSON 09

Objects

An object stores related information as key-value pairs. 

let student = {
    name: "Ali",
    age: 15,
    city: "Lahore"
};

console.log(student.name);
console.log(student.age);
LESSON 10

Functions

A function is a reusable block of code that performs a task. 

function greet(name) {
    console.log("Hello " + name);
}

greet("Ali");
greet("Sara");

Function with Return

function add(a, b) {
    return a + b;
}

let result = add(5, 3);
console.log(result);
LESSON 11

Basic OOP

OOP stands for Object-Oriented Programming. It organizes code using classes and objects.

Class & Object

class Student {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        console.log("Hello " + this.name);
    }
}

const student1 = new Student("Ali", 15);

student1.greet();
console.log(student1.age);
  • Class: A blueprint for creating objects.
  • Object: An instance created from a class.
  • constructor(): Initializes a new object.
  • this: Refers to the current object in this example.

Inheritance

Inheritance allows a class to extend another class. 

class Animal {
    speak() {
        console.log("Animal sound");
    }
}

class Dog extends Animal {
    bark() {
        console.log("Woof!");
    }
}

const dog = new Dog();
dog.speak();
dog.bark();
Learn classes, objects, constructors and inheritance first. You can study advanced OOP concepts later.
