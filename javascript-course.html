LESSON 01

Introduction to JavaScript

JavaScript is a programming language used to make websites interactive. HTML creates the structure, CSS controls the design, and JavaScript adds functionality.

What can JavaScript do?

  • Respond to button clicks.
  • Change text and HTML elements.
  • Validate forms and user input.
  • Create interactive websites and applications.
Remember: HTML creates the structure, CSS styles the page, and JavaScript controls behavior.

First JavaScript Example

console.log("Hello, World!");
LESSON 02

Variables

Variables store information that can be used throughout a program.

Types of variable declarations

  • let: A variable that can be reassigned.
  • const: A variable that cannot be reassigned.
  • var: An older way to declare variables.
let name = "Mohib";
let age = 16;
const country = "Pakistan";

console.log(name);
console.log(age);
Tip: Use let when reassignment is needed and const when the variable should not be reassigned.
LESSON 03

Data Types

A data type describes what kind of value a variable holds.

Important JavaScript data types

  • String — text, such as "Hello".
  • Number — numeric values, such as 25.
  • Boolean — true or false.
  • Undefined — a variable without an assigned value.
  • Null — an intentionally empty value.
  • Object — collections of related data.
  • BigInt and Symbol — additional primitive types.
let username = "Mohib";
let marks = 90;
let passed = true;
let result = null;

console.log(typeof username);
console.log(typeof marks);
LESSON 04

JavaScript Operators

Operators perform calculations and compare values.

Types of operators

  • Arithmetic: +, -, *, /, %, **
  • Assignment: =, +=, -=, *=
  • Comparison: ===, !==, >, <, >=, <=
  • Logical: &&, ||, !
  • Increment and decrement: ++, --
let a = 10;
let b = 5;

console.log(a + b);  // 15
console.log(a > b);  // true
console.log(a === b); // false
LESSON 05

If Else Conditions

Conditions allow JavaScript to make decisions based on whether an expression is true or false. 

let age = 20;

if (age >= 18) {
    console.log("Valid age");
} else {
    console.log("Under 18");
}

Condition types

  • if
  • if else
  • else if
  • Nested if statements
  • Ternary operator
LESSON 06

Switch Statement

A switch statement selects a matching case from several possible options. 

let day = 2;

switch (day) {
    case 1:
        console.log("Monday");
        break;
    case 2:
        console.log("Tuesday");
        break;
    default:
        console.log("Unknown day");
}
Remember: break prevents execution from continuing into the next case.
LESSON 07

Loops

Loops repeat a block of code while a condition remains true or while items remain to be processed.

Main loop types

  • for loop
  • while loop
  • do...while loop
  • for...of loop
  • for...in loop
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Also learn break and continue to control loop execution.

LESSON 08

Functions

Functions are reusable blocks of code that perform specific tasks.

Important concepts

  • Function declaration and expression
  • Parameters and arguments
  • Return statement
  • Arrow functions
  • Local and global scope
  • Callbacks and closures
function add(a, b) {
    return a + b;
}

let result = add(5, 3);
console.log(result); // 8
LESSON 09

Arrays

Arrays store multiple values inside one variable. Each item has an index, starting from zero. 

let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[0]); // Apple
console.log(fruits.length); // 3

Topics to learn

  • Creating and accessing arrays
  • Changing array elements
  • Adding and removing elements
  • Looping through arrays
LESSON 10

Array Methods

Array methods help you process and manage collections.

  • push() and pop()
  • shift() and unshift()
  • slice() and splice()
  • includes() and indexOf()
  • forEach() and map()
  • filter(), find() and reduce()
  • some() and every()
let numbers = [1, 2, 3, 4];

let doubled = numbers.map(function(num) {
    return num * 2;
});

console.log(doubled); // [2, 4, 6, 8]
LESSON 11

Objects

Objects store related information as key-value pairs. They can also contain functions called methods. 

let student = {
    name: "Ali",
    age: 16,
    city: "Lahore"
};

console.log(student.name);
console.log(student["age"]);

Learn these concepts

  • Object properties and methods
  • Dot and bracket notation
  • Adding and deleting properties
  • Object destructuring
  • Spread syntax and optional chaining
LESSON 12

Strings

Strings represent text. JavaScript provides built-in methods for searching, extracting and changing text. 

let message = "Hello JavaScript";

console.log(message.length);
console.log(message.toUpperCase());
console.log(message.includes("JavaScript"));
console.log(message.slice(0, 5));

Important methods

length, includes(), indexOf(), slice(), replace(), split(), trim(), toLowerCase() and toUpperCase().

LESSON 13

Numbers & Math

JavaScript provides numeric conversion functions and a Math object for common calculations. 

let price = 19.8;

console.log(Math.round(price)); // 20
console.log(Math.floor(price)); // 19
console.log(Math.ceil(price));  // 20
console.log(Math.max(10, 20, 30)); // 30

let number = Number("25");
console.log(number);

Learn Number(), parseInt(), parseFloat(), Math.random(), Math.min(), and Number.isNaN().

LESSON 14

DOM Introduction

DOM stands for Document Object Model. The browser represents an HTML document as a tree of objects. JavaScript can access and update these objects.

What can the DOM do?

  • Select HTML elements.
  • Change text and HTML content.
  • Change styles and CSS classes.
  • Create and remove elements.
  • Respond to user interactions.
Remember: The DOM connects JavaScript with the elements displayed on your webpage.
LESSON 15

Selecting HTML Elements

Before changing an element, JavaScript usually needs to select it from the document. 

document.getElementById("title");

document.querySelector(".box");

document.querySelectorAll("p");

document.getElementsByClassName("card");

document.getElementsByTagName("h1");

Important methods

  • getElementById()
  • querySelector()
  • querySelectorAll()
  • getElementsByClassName()
  • getElementsByTagName()
LESSON 16

Changing HTML Elements

After selecting an element, you can change its text, styles, attributes, and CSS classes. 

let title = document.getElementById("title");

title.textContent = "Welcome Developer";

title.style.color = "blue";

title.classList.add("highlight");

title.setAttribute("title", "Main heading");

Important properties and methods

  • textContent and innerHTML
  • style and classList
  • getAttribute() and setAttribute()
  • createElement() and append()
  • remove() and removeChild()
LESSON 17

JavaScript Events

Events let your website respond to actions such as clicking a button, typing in an input, or submitting a form.

Common events

  • click
  • input and change
  • submit
  • mouseover and mouseout
  • keydown and keyup
let button = document.querySelector("#btn");

button.addEventListener("click", function() {
    console.log("Button clicked!");
});
Tip: addEventListener() is a common way to attach event handlers to HTML elements.

localStorage saves string data in the browser so it can remain available across page reloads. 

localStorage.setItem("username", "Mohib");

LESSON 21

JSON

JSON is a text format commonly used to exchange structured data between applications and APIs. 

const user = {
    name: "Ali",
    age: 16
};

const jsonData = JSON.stringify(user);

const originalData = JSON.parse(jsonData);

console.log(originalData.name);

Important methods

  • JSON.stringify() converts supported data into JSON text.
  • JSON.parse() converts valid JSON text into a JavaScript value.
LESSON 22

Async & Await

Asynchronous JavaScript helps handle operations that may finish later, such as network requests. 

async function getMessage() {
    return "Hello!";
}

getMessage().then(function(message) {
    console.log(message);
});

Learn these concepts

  • Callbacks
  • Promises
  • async and await
  • Promise.then() and catch()
  • try and catch with asynchronous code
LESSON 23

Fetch API

The Fetch API allows JavaScript to send network requests and receive responses, often from a web API. 

async function loadData() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/posts/1"
        );

        if (!response.ok) {
            throw new Error("Request failed");
        }

        const data = await response.json();

        console.log(data);
    } catch (error) {
        console.log(error.message);
    }
}
Remember: fetch() does not reject automatically for HTTP errors such as 404. Check response.ok to handle them.
LESSON 24

Error Handling

Error handling helps a program respond to problems without failing unexpectedly. 

try {
    let data = JSON.parse("{invalid JSON}");
    console.log(data);
} catch (error) {
    console.log("Something went wrong");
} finally {
    console.log("Operation finished");
}

Important concepts

  • Syntax errors
  • Reference errors
  • Type errors
  • try, catch and finally
  • throw new Error()
  • Debugging with browser developer tools
