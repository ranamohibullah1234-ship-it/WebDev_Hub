CSS Fundamentals

Learn the basics before moving to advanced layouts.

LESSON 01

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML elements and control the appearance of a website.

What can CSS do?

  • Change text and background colors.
  • Set fonts, sizes and spacing.
  • Create layouts and responsive pages.
  • Add hover effects and animations.
Remember: HTML creates the structure, while CSS controls how that structure looks.
LESSON 02

CSS Syntax

A CSS rule contains a selector and a declaration block. Each declaration usually has a property and a value.

CSS Example
h1 {
    color: blue;
    font-size: 32px;
}
  • h1: Selector
  • color: Property
  • blue: Value
LESSON 03

How to Add CSS

There are three common ways to add CSS to HTML.

1. Inline CSS

<h1 style="color: red;">Hello</h1>

2. Internal CSS

<style>
h1 {
    color: blue;
}
</style>

3. External CSS

<link rel="stylesheet" href="style.css">
Best practice: Use external CSS for larger projects because it keeps HTML and CSS separate.
LESSON 04

CSS Selectors

Selectors choose which HTML elements you want to style.

/* Element selector */
p {
    color: gray;
}

/* Class selector */
.card {
    padding: 20px;
}

/* ID selector */
#title {
    color: purple;
}

/* Universal selector */
* {
    box-sizing: border-box;
}
A class starts with a dot (.) in CSS, while an ID starts with a hash (#).
LESSON 05

Colors & Backgrounds

Use CSS colors and backgrounds to give your page style.

body {
    background-color: #f4f7ff;
}

h1 {
    color: #635bff;
}

.card {
    background-color: white;
    background-image: linear-gradient(
        to right, #635bff, #8b5cf6
    );
}

Colors can be written as names, HEX, RGB or HSL values.

LESSON 06

Text & Fonts

Control text size, alignment, weight and font style.

p {
    font-family: Arial, sans-serif;
    font-size: 16px;
    font-weight: 400;
    line-height: 1.7;
    text-align: left;
}

h1 {
    text-decoration: none;
    letter-spacing: 1px;
}
LESSON 07

The CSS Box Model

Every HTML element can be understood as a box.

  • Content: The text or image inside.
  • Padding: Space inside the border.
  • Border: The edge around the element.
  • Margin: Space outside the border.
.card {
    width: 300px;
    padding: 20px;
    border: 2px solid #ddd;
    margin: 20px;
    box-sizing: border-box;
}
LESSON 08

Height, Width & Units

CSS units control dimensions and spacing.

.container {
    width: 90%;
    max-width: 1100px;
    min-height: 200px;
    padding: 2rem;
    margin: 0 auto;
}

Common units: px, %, rem, em, vw and vh.

LESSON 09

CSS Display

The display property controls how elements are laid out.

.container {
    display: flex;
    gap: 20px;
}

.item {
    display: block;
}

.hidden {
    display: none;
}

Common values include block, inline, inline-block, flex and grid.

LESSON 10

CSS Position

Positioning helps you control where an element appears.

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}

Main values: static, relative, absolute, fixed and sticky.

LESSON 11

CSS Flexbox

Flexbox is useful for arranging items in a row or column.

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    flex-wrap: wrap;
    gap: 20px;
}
  • justify-content aligns items on the main axis.
  • align-items aligns items on the cross axis.
  • flex-wrap allows items to move to another line.
LESSON 12

CSS Grid

Grid helps create layouts with rows and columns.

.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

For flexible cards, try repeat(auto-fit, minmax(220px, 1fr)).

LESSON 13

Borders, Radius & Shadows

These properties help you make modern cards and buttons.

.card {
    border: 1px solid #e5e7eb;
    border-radius: 16px;
    box-shadow: 0 8px 24px rgba(0, 0, 0, 0.08);
}
LESSON 14

Hover Effects & Transitions

Use hover effects to make interactive elements feel smoother.

.button {
    background: #635bff;
    color: white;
    transition: transform 0.3s ease,
                background 0.3s ease;
}

.button:hover {
    background: #4940e8;
    transform: translateY(-3px);
}
LESSON 15

Responsive CSS

Media queries let you apply styles at different screen widths.

/* Tablet and smaller screens */
@media (max-width: 768px) {
    .container {
        grid-template-columns: 1fr;
    }

    h1 {
        font-size: 30px;
    }
}
Responsive websites adapt to different screens, including phones, tablets and laptops.
