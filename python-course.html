LESSON 02

Variables & Data Types

A variable stores a value that your program can use. Python automatically determines its data type. 

name = "Ali"       # String
age = 15           # Integer
height = 5.5       # Float
is_student = True  # Boolean

print(name)
print(age)

Main Data Types

  • String (str): Text, e.g. "Hello"
  • Integer (int): Whole numbers, e.g. 10
  • Float: Decimal numbers, e.g. 5.5
  • Boolean (bool): True or False
LESSON 03

Input & Output

Use print() to display information and input() to receive text from the user. 

name = input("Enter your name: ")
print("Welcome", name)

Example output:

Enter your name: Ali
Welcome Ali
Remember: input() returns text. Use int() when you need a whole number.
LESSON 04

Python Operators

Operators perform calculations and comparisons.

a = 10
b = 3

print(a + b)   # 13

LESSON 05

If-Else Conditions

Conditions let your program make decisions based on whether something is true or false. 

age = 18

if age >= 18:
    print("Adult")
else:
    print("Under 18")

Use elif when you need to check another condition.

LESSON 06

For & While Loops

Loops repeat code instead of making you write it again and again.

For Loop

for i in range(1, 6):
    print(i)

While Loop

count = 1

while count <= 3:
    print(count)
    count += 1
LESSON 07

Lists, Tuples & Dictionaries

List

A list stores multiple items and can be changed.

fruits = ["Apple", "Mango", "Banana"]
print(fruits[0])

fruits.append("Orange")

Tuple

A tuple stores multiple items and cannot be changed after creation.

colors = ("Red", "Blue", "Green")
print(colors[1])

Dictionary

A dictionary stores data as key-value pairs.

student = {
    "name": "Ali",
    "age": 15
}

print(student["name"])

LESSON 09

OOP (Object-Oriented Programming)

OOP is a way of organizing code using classes and objects. It helps group related data and functions together.

1. Class & Object

A class is a blueprint. An object is an instance created from that class. 

class Student:
    def greet(self):
        print("Hello, student!")

student1 = Student()
student1.greet()

2. The __init__() Method

__init__() initializes an object's data when the object is created. 

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

student1 = Student("Ali", 15)

print(student1.name)
print(student1.age)

3. Inheritance

Inheritance lets one class reuse or extend features from another class. 

class Animal:
    def speak(self):
        print("Animal makes a sound")

class Dog(Animal):
    def bark(self):
        print("Woof!")

dog = Dog()
dog.speak()
dog.bark()

4. The Four Main OOP Concepts

  • Encapsulation: Keeping data and related methods together and controlling access to data.
  • Inheritance: Reusing or extending another class.
  • Polymorphism: Different objects can respond to the same method in different ways.
  • Abstraction: Hiding implementation details and exposing the essential features.
OOP tip: First understand classes, objects and __init__(). Then move on to the four concepts.

Mini Project: Student Information

Use a class to store a student's name and age.

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def show_info(self):
        print("Name:", self.name)
        print("Age:", self.age)

student1 = Student("Ali", 15)
student1.show_info()
